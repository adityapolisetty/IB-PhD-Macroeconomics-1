Consumption over time

How much can a household afford to consume? Wealth paths, consumption choices and the terminal condition.

Explore the model ↓Download notebook ↗

The intuition

A household can choose its initial consumption, but it cannot choose that number independently of its lifetime resources. A small initial mistake gets carried forward by the consumption growth rule. Over many years, that mistake changes the wealth path dramatically.

Choosing too much consumption eventually requires ever more borrowing. Choosing too little leaves resources unused. The optimal initial choice lies between these failures.

The subtle point is that wealth itself need not approach zero. The terminal condition concerns wealth measured in present-value units. A growing asset stock can have a shrinking present value when it grows more slowly than the interest rate.

Pause & predict

If a(t) keeps increasing, must the terminal condition fail?

Discuss the answer

No. Compare its growth rate with the discount rate. What matters here is the limiting value of e⁻ʳᵗa(t), not the asset level on its own.

Explore the mechanism

Start with consumption slightly below the optimum. Inspect discounted wealth, then switch to wealth in levels. Finally move the guess just above the optimum and look for the zero-asset event.

The next code step

The numerical solver tracks both variables in a consistent order:

def rhs(t, state):
    assets, consumption = state
    return [r * assets + wage - consumption,
            g * consumption]

An event function can stop the calculation when assets hit zero. That event is a useful diagnostic for an overly high guess in this example. Underconsumption instead needs a discounted-wealth check or a sufficiently long horizon.

What to take away

Inspect the economically relevant quantity before judging a numerical path. An upward wealth curve is not enough to identify a terminal-condition failure. Discounting exposes the lifetime budget mismatch.
